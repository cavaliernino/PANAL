# web — the PANAL PWA

MapLibre GL + deck.gl `H3HexagonLayer`. No API key, no app store, no install
friction. This is the first phase where PANAL becomes visible.

Chosen over an Android-first path so the risk engine can be seen and critiqued
in days rather than weeks. Android is rebuilt against this same API in Phase 6.

Must deliver: the hex heat map, geolocation, the three-component breakdown per
cell, the time series, the data-date banner, and WCAG-compliant colour choices
that survive being the only signal on the screen.
